# Contributing Guidelines

Thank you for your interest in contributing to the SEC Financial Data Pipeline and RAG System.

## Development Workflow

1. Fork the repository and create a dedicated feature branch from `develop`.
2. Ensure all Python code adheres to PEP 8 standards.
3. Run the automated test suite before opening a pull request:
   ```bash
   python -m pytest tests/ -v
   ```
4. Follow the Conventional Commits specification for all commit messages.

## Pull Request Process

1. Open a pull request targeting the `develop` branch.
2. Provide a concise summary of the changes, related issues, and verification steps.
3. Maintain documentation integrity and update README.md when adding new components.
