# Rule: Strictly No Emojis or Decorative Symbols

## Context
Applies to all files in the repository: markdown documentation, code comments, commit messages, and CLI outputs.

## Requirements
1. Prohibit all emojis, pictorial glyphs, and decorative unicode symbols.
2. Maintain clean, high-density, professional technical documentation in plain English.
3. Use standard Markdown syntax (headings, bullet points, fenced code blocks, tables) for visual hierarchy without decorative elements.
